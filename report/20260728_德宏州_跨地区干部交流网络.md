### 4.4 滇西边境干部交流模式特征

****总结模式:**
1. 保山－德宏：**双向交流最密集** — 保山干部调入任要职，德宏干部调入保山任职
2. 大理→德宏：**单向流动** — 大理干部到德宏任职，反向较少
3. 临沧→德宏：**较少** — 两州之间经济联系较弱，交流相对少
4. 西双版纳↔德宏：**由赵刚案例**体现为对调交流，但非定期模式
5. 省级→德宏：**关键角色派驻** — 纪委书记、组织部、政法委等核心位置由省派出

## 五、副职级干部交流特征

### 5.1 州委副书记
- 常从省级机关或保册、大理调任
- 在本州晋升后，有机会接任州长或副书记

### 5.2 州纪委书记
- 基本从省纪委纪检监察组"下派"
- 在任结束后，多返回省纪委监委或调任其他地州

### 5.3 州委组织部部长
- 通常从省委组织部或省直机关调任
- 是"空降"程度最高的岗位之一

### 5.4 公系统要职
- 州公安局局长：基本由省公安厅调任或异地互调
- 州法院院长：省高院或异地中院调任
- 州检察院检察长：省检察院调任

## 八、交流网络类型塔

**第一层: 城市群级别**
1. **保山—德宏**：最核心——交通便捷、地理相邻、语言相近 ← 最强交流
2. **大理—德宏**：次核心——审美潜力但距离较远
3. **怒江—德宏**：较少交流——地理限制（高山）
4. **临沧—德宏**：较少——方向不同（临沧更靠近昆明和缅甸东部）

**第二层: 省级级别**
- 省委→德宏空降（关键岗位）
- 德宏→省厅调（提拔）
- 德宏与其他地州对调（赵刚类案例）

**第** 跨省交流 */
- 德宏出现的外省籍干部不多——云南边境省份内部用人为主
- 少数来自湖南、山东等地的短派援滇干部

## 九、关键洞察

### 9.1 德宏干部的"流向"优先级

```
      保山 ←→ 德宏  (最高频)
         ↑
         |
 大理/省级——→德宏  (第二层)
         ↓
     从德宏 → 省级或昆明 (晋升)
         ↓
     西双版纳/其他（特例）
```

### 9.2 重要的"战略级"关联TOP 5
1. **姜山（省委组织部→德宏州委书记）**：其是否有从省到德再回省趋势，是现任书记动向的关键
2. **赵刚（德宏→西双版纳）**：两年民族自治州首脑对调，是政策凯恩斯主义还是个体路径？
3. **何胜/姚正良/XXX**（保山→德宏干部群）：查清该群体规模即可确定德宏—保山关联强度
4. **正在任州长卫岗**的去向他（连任/提/调）是当前最高关注点
5. **德宏落马干部**：不良于云俊强等被查，对德宏系统的网络有重要冲击

### 3. 系统特征

德宏州干部交流呈现"三环结构":
- **外环**: 保山—德宏（大功率双工）
- **中环**: 省级送出（空降）
- **内环**: 德宏内部少量人晋升

这种结构解释了为何德宏的"本州派"较弱——既重要的政治资源岗位大多由外来或空降者担任，内环融合范围狭小。但常务副职、民族事务等"软性"岗位仍保留本地派任，以维持自治区域平衡。
