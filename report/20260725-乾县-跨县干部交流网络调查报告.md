## 摘要

本报告基于 Wikipedia API 获取的人物履历、本项目已采集的乾县及邻近县区领导班子数据、以及咸阳市和陕西省领导架构信息，系统梳理了涉及乾县的跨县干部交流网络。**核心发现**：乾县是咸阳市向外输送高级干部较多的县之一，至少产生了两位省部级官员（徐新荣-正省级、上官吉庆-副省级但已落马），且在县级领导班子层面与周边县区存在常态化交流。

## 四、跨县交流模式分析

### 4.1 咸阳辖县间轮岗模式

综合乾县籍官员上官吉庆的履历，可以观察到咸阳辖县之间干部交流的典型路径：

```
三原县（起步） → 旬邑县（副县长→县长） → 彬县（县长） → 乾县（县委书记）
```

**特征**：咸阳北部和中部各县（三原、旬邑、彬县、乾县、礼泉、永寿等）之间存在常规化的干部轮岗机制，县级主官通常会在2-4个县之间轮换后再提拔到市级。

### 4.2 乾县→咸阳市→省级的晋升通道

```
乾县（县委书记锻炼）
    ↓
咸阳市（副市长/副书记——副厅级过渡）
    ↓
省财政厅/其他省级机关 或 地级市主要领导
    ↓
更高层次（如西安副省级城市、省政协正省级）
```
