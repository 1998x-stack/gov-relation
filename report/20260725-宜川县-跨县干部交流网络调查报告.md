# 宜川县跨县干部交流网络调查报告

> 宜川县（延安市，陕西省）与周边县区——宝塔区、延长县、延川县、富县、洛川县、黄龙县、韩城市（渭南市）——的干部流动模式调查
> 调查日期：2026-07-25

---

## 一、摘要

本报告聚焦宜川县与周边县区之间的干部交流网络。通过公开资料（百度百科、政府网站、新闻报道）梳理了宜川县历任及现任主要领导（县委书记、县长）的职业履历，识别出**5例已确认的跨县调动**，涉及宜川、洛川、延川、延长、黄龙5个县区。主要模式为：县级主要领导（县长/县委书记）多为**异地调任**，本地干部很少直接升任本级正职。

## 四、跨县交流模式分析

### 4.1 县委书记的来源模式

| 时期 | 书记 | 来源 |
|------|------|------|
| 2014-2021 | 左怀理 | 甘泉县（团委→宜川县长→书记） |
| 2021-2024 | 高勇 | 延安市级部门（具体前职待查） |

**模式**：县委书记通常从**市级机关空降**或从**异地临近县调任**。左怀理是跨县晋升（甘泉→宜川），高勇是市级空降。

### 4.2 县长的来源模式

| 时期 | 县长 | 来源 |
|------|------|------|
| 2012-2014 | 左怀理（兼任） | 甘泉→宜川副书记→县长 |
| ~2020 | 前任 | 待查 |
| 2021-2025.07 | 薛延飞 | 宜川常务副→县长（本地晋升） |
| 2025.07至今 | 李岗 | **延川县**副书记→宜川县长 |

**模式**：县长有两条路径：
1. **本县常务副→县长**（如薛延飞：宜川常务副→宜川县长）
2. **外县副书记→县长**（如李岗：延川副书记→宜川县长）

### 4.3 跨县调动方向

```
                 洛川 ←── 宜川 (薛延飞)
                           ↑
                         延川 (李岗)
                           ↑
                     延长(李岗籍贯)
                           
    甘泉 ──→ 宜川 (左怀理)
    黄龙 ──→ 洛川 (鲁强)
```

### 4.4 主要规律

1. **横向平调为主**：跨县调动多为平级（正处级/副处级），少见越级提拔
2. **邻近县优先**：调任多发生在相邻县区之间（宜川↔延川、宜川↔洛川、延川↔延长）
3. **市级干部下沉**：县委书记常从市级部门空降至县
4. **异地任职普遍**：没有一位县委书记或县长是宜川本地人，确保回避原则
5. **本地常务副晋升**：部分县长由本县常务副县长晋升（薛延飞模式）
6. **籍贯地调动线索**：延长县是重要的干部输出地（李岗延长人→延川→宜川）

## 八、结论

### 已确认的宜川县跨县交流路径（共3条）

1. **延川县 → 宜川县**：李岗由延川县委副书记调任宜川县长（2025）
2. **甘泉县 → 宜川县**：左怀理由甘泉团系统调任宜川县长，后升书记（2012-2014）
3. **宜川县 → 洛川县**：薛延飞由宜川县长调任洛川县长（2025）

### 涉及周边县区的跨县交流（2条）

4. **黄龙县 → 洛川县**：鲁强由黄龙副县长调任洛川副县长
5. **延长县**：宜川县长李岗为延长人，显示延长-延川-宜川的跨县流动走廊

### 核心模式总结

- **县委书记**：主要来自市级机关（高勇）或跨县调任（左怀理）
- **县长**：来自外县副书记平调（李岗）或本县常务副晋升（薛延飞）
- **跨县走廊**：延长→延川→宜川→洛川 构成一条东西向的干部流动通道
- **籍贯效应**：延长、甘泉两县是重要的干部"输出地"
- **回避制度**：所有正县级主要领导均非宜川本地人
