## 五、调研局限性

1. **县委领导班子信息获取不完整**：县政府官网领导之窗仅列出县政府系统领导，无县委除县长外其他班子成员独立页面。县委组织部、县纪委等不设独立领导信息页面在县官网。
2. **Baidu Baike 不可访问**：百度百科拒绝自动抓取，无法查阅吴青珊、胡显平、孔金峰等人的百科条目。
3. **搜索引擎速率限制**：Exa API 己达免费额度上限；百度搜索强制验证码屏蔽自动访问。
4. **CMS动态加载**：庆元县政府新闻列表页通过JavaScript动态刷新，无法直接解析列表获取完整新闻索引。
5. **无便捷任前公示来源**：丽水市委组织部任前公示通常发布在丽水市政府网或者“丽水发布”微信公众号，未建立可以全文检索的在线存档。

### 下一步建议
1. 通过 Playwright（需要 Chromium 安装）访问庆元县政府网站新闻列表，获取更多新闻报道以确认县委常委成员职务
2. 搜索“丽水市/庆元县 任前公示”搜索丽水市委组织部发布的公示文档
3. 通过澎湃新闻、浙江新闻等媒体搜索庆元县领导班子的专稿
