## 2. 关键跨县交流个案详解

### 2.1 包华：蓬莱区 → 栖霞市（市委书记）

**发现来源**：2021-04-23 栖霞市领导干部会议（烟台广播电视台/网易新闻）

包华经山东省委研究决定从原驻地调任栖霞市委书记。此前他由烟台市委常委、组织部部长高建广护送上任。

本次调动的背景：2021年初笏山金矿重大事故，原市委书记姚秀霞和市长朱涛被免职刑拘。包华作为"救火队长"从蓬莱（烟台沿海经济强区）调往栖霞（内陆欠发达县级市）。

此举体现了：
- **烟台市委的跨县调度机制**：由市委书记统一调配全市县级干部
- **沿海→内陆的流向规律**：经济发达区干部向欠发达区输送
- **重大事故后的组织处理模式**：撤换+空降的组合拳

### 2.2 赵永刚：潍坊→烟台（跨市调入）

实际上，赵永刚并非烟台市内跨县交流，而是跨了地级市——寿光（潍坊市辖）→潍坊经济开发区→烟台保税港区→栖霞。

**关键转移路径**：
1. 寿光市委常委、常务副市长 **←** 潍坊经济区
2. 潍坊经济开发区党工委副书记、管委会主任（县级）←
3. **2020年**：烟台保税港区工委委员、管委副主任（副厅级）——**跨市调入烟台**
4. 2021-12：栖霞市委副书记、提名市长候选人
5. 2023-08：栖霞市委书记

这说明烟台对栖霞的人事战略是：**从烟台以外引进有经济区（开发区/保税港）经验的干部**，直接掌舵经济相对落后的栖霞。

### 2.3 于晓丽：龙口市北马镇 → 栖霞市副市长

**，来源**：2025年中共烟台市委组织部任前公示（2025-08-27）和栖霞市人大任命（2025-09-08）

这是目前**唯一详细记录的烟台市内跨县乡镇→县级提拔**案例。于晓丽从龙口市北马镇党委书记（正科级）直接提升为栖霞市副市长（副县级），是典型的**跨县晋升**。

**模式特征**：
- **原单位**：龙口市（烟台经济强市）北马镇（镇级）
- **目标单位**：栖霞市（烟台经济弱市）副市长（县级）
- **方向**：发达县基层骨干→欠发达县县级岗位
- **公开程序**：烟台市委组织部统一公示 → 栖霞市人大任命

### 2.4 李波——烟台市包华-栖霞的不兼任职

李波在任烟台市副市长期间曾兼任栖霞市委书记。2021-04卸任兼职后，由包华担任专职书记。

## 3. 跨县交流模式

### 模式A："外来派"（烟台市级—县级流动）
- 路径：烟台市委/市级单位 → 栖霞市委/市
- 案例：李波（烟台副市长兼栖霞书记）、包华（蓬莱→栖霞）
- 一般出现在：书记换届、事故追责后的平稳期
- **代表性**

### 模式B："经济区—经济弱区"对口帮扶
- 路径：其他经济强县→栖霞
- 案例：赵永刚（寿光/潍坊经济区→栖霞）、于晓丽（龙口→栖霞）
- 驱动：带着经济管理经验去欠发达地区
- 烟台市的普遍趋势

### 模式C："// catch"

通过人才引进/选秀（2021年栖霞市竞争性选拔年轻干部），大批**本地优秀年轻干部**得到提拔（5名正科长、30名副科长）。但这批人是由栖霞市内竞争而非跨县输入。

## 总结

### 会议号栖霞市跨县干部交流的三发现

1. **流入大于流出**——栖霞是净调入境区（与中国多数欠发达县调出一致）
2. **"消村方向"明确**：从蓬莱沿海、潍坊开发区县级市交去→向栖霞相对滞后区如：  
   外来的带着开发经验的人才和经手项目调动
3. **市委书记—镇级均插手**：交流可跨市（赵永刚潍坊→烟台）、跨县级（于晓丽龙口→栖霞）

### 人口调度机制：

烟台市委组织部是县级干部调派的关键——所有调拨都通过烟台市委组织部任前公示、市委会议宣布完成，掌握全市统筹权。
