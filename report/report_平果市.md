# 平果市领导班子工作关系网络调查报告

## 1. 现任市委书记：凌玉强

**凌玉强**，男，壮族，1969年5月出生，广西田阳县人，在职研究生学历，1992年5月加入中国共产党，1993年7月参加工作。

**完整履历**：
- 1993.07—1994.05 广西田阳县委党史办公室干事
- 1994.05—1996.04 广西田阳县委组织部组织股干事、副股长（1995.03—1996.02挂任田阳县雷圩乡伏王村支部副书记）
- 1996.04—2000.12 广西百色地委组织部组织科科员、副主任科员、副科长、主任科员
- 2000.12—2002.04 广西百色地委办公室第一秘书科主任科员、副科长
- 2002.04—2005.01 广西百色（地）委办公室干部教育科科长
- 2005.01—2006.07 广西凌云县委常委、组织部部长
- 2006.07—2009.05 广西田东县委常委、组织部部长
- 2009.05—2010.03 广西西林县委常委、副县长
- 2010.03—2019.03 广西田东县委常委、副县长→市政府副秘书长→市发改委副主任→市物价局局长
- 2019.03—2022.08 广西百色市医疗保障局党组书记、局长
- 2022.08—2023.09 广西百色市委组织部副部长（正处长级）、市人社局局长
- 2023.09至今 广西百色市平果市委书记、人武部党委第一书记

**晋升路径**：组织系统出身（组织部工作约17年），经过凌云、田东、西林三个县区的副处级实岗历练后进入市直部门，逐年晋升至正处级，2023年下派主政平果市。

**信息来源**：https://baike.baidu.com/item/%E5%87%8C%E7%8E%89%E5%BC%BA/4819658、http://m.gxcounty.com/show-30-179960-0.html

## 2. 现任市长：陆长何（代理）

**陆长何**，男，壮族，1979年3月出生，广西百色人，全日制大学学历，2010年12月加入中国共产党，2004年12月参加工作。

**履历**：
- 2004.12—~2017 广西田东县委组织部干事（早期履历信息不全）
- ~2017—2019.04 广西田东县委组织部常务副部长（正科长级）
- 2019.05—2020.09 广西百色市党建工作办公室主任（副处长级）
- 2020.09—2023.08 靖西市委常委、组织部部长
- 2023.08—2025.11 田东县委常委、常务副县长、三级调研员
- 2025.11—2026.07 田东县委副书记
- 2026.07至今 平果市人民政府副市长、代理市长

**注解**：陆长何2026年7月9日经平果市人大常委会任命为代市长，尚未进行正式市长选举。前任市长郭嘉去向有待查证。

**信息来源**：http://www.gxcounty.com/zhengwu/rsrm/196759.html

## 3. 原市长：郭嘉

**郭嘉**，男，汉族，1984年6月出生，河南登封人，清华大学工学博士（工学博士，热能工程系），2013年7月参加工作的广西定向选调生。

**履历**：
- 2013.07 广西定向选调生，平果县政府干部
- 2014.07 平果县政府主任科员
- 百色市委办公室副调研员
- 靖西市化峒镇党委书记（保留副处级）
- 田阳区委副书记
- 2021.07—2021.09 平果市委副书记、副市长、代理市长
- 2021.09—2026.06 平果市委副书记、市人民政府市长
- 2026.06 离任（去向待查）

**特色**：80后清华博士选调生，连续在百色工作13年，从平果县基层干部成长为市长。

## 7. 关系网络分析

### 强连接（确认的工作交集）
1. **凌玉强—秦运德、黄波、黄学辉、黄瑞华、苏伟、杨华娟、王艳榜**：作为市委书记与每位常委直接共事
2. **凌玉强—罗成**：前后市委书记（2023年9月交迭）
3. **郭嘉—陆长何**：前后市长（2026年7月交迭）
4. **罗成—郭嘉**：书记-市长正职搭档（2021-2023）
5. **黄瑞华—凌玉强**：田东县委同时任职系（黄瑞华曾任田林，凌玉强曾任田东）

### 跨县调动模式
百色市县级领导的跨县调动十分频繁：
- **凌玉强**：田阳→百色→凌云→田东→西林→百色→平果
- **陆长何**：田东→百色→靖西→田东→平果
- **黄瑞华**：田林→平果
- **何家兴**：西林→百色→德保→田阳→平果→德保

## 关键洞察

1. **组织系统主导**：现任书记凌玉强及多名核心常委（黄瑞华、苏伟、陆长何）均出身组织系统，体现百色市委对平果干部配置的组织导向
2. **罗成案件余波**：原书记罗成落马后，郭嘉作为清华选调生的回顾，2026年离任是否及关联待查
3. **80后群体崛起**：郭嘉（1984）、王艳榜（1987）、黄瑞华（1980）等80后占比高于平均值
4. **选调生文化**：郭嘉（清华博士）、王艳榜（北京理工大学硕士）均为广西定向选调生，反映广西定向引进高学历人才的渠道输出
