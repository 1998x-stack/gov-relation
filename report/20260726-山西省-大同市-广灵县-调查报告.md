## 7. 周边县区人事交流网络

### 大同市东部三县联动格局

广灵县与阳高县、灵丘县相邻，同属大同市东部农业经济区：

```
阳高县 —（东接）— 天镇县
   |
（南接）
   |
广灵县 —（东接）— 灵丘县
```

### 可能存在的交流模式（需验证）

| 模式 | 说明 |
|------|------|
| 广灵 ↔ 阳高 | 相邻县之间干部交流（大同东部县群内部流动） |
| 广灵 ↔ 灵丘 | 同属大同南部山区县 |
| 广灵 → 市直 | 从广灵县级岗位调任市直部门 |
| 市直 → 广灵 | 从大同市委/市政府部门到广灵任职 |
