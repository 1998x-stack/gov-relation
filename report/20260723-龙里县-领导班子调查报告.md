## 7. 周边县区人事交流网络

### 关键发现：福泉走廊

两位连续龙里县委书记均经过**福泉市**中转：

```
冯异星：福泉市委常委/组织部长 → 常务副市长 → 龙里县长 → 龙里书记
郭兴文：长顺县 → 福泉市委副书记 → 黔南州委 → 龙里书记
```

### 跨市交流

孙猛从**贵阳市系统**跨地市调入龙里县，路径为：
```
乌当区（贵阳）→ 观山湖区（贵阳）→ 双龙航空港经济区（跨贵阳/黔南）
→ 龙里县（黔南）
```

这得益于双龙航空港经济区——一个横跨贵阳和黔南的特殊经济区，成为跨地市干部交流的重要平台。

### 仕途上升通道

龙里县委书记去向：冯异星 → **黔南州直机关**（公积金中心→州政府办）。  
尚未发现直接从龙里书记升任其他县委书记或更高实职的案例。
