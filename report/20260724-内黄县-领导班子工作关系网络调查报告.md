## 6. 工作关系网络分析

### 政府核心工作关系

基于2026年7月23日的领导分工，内黄县政府内部工作关系网络呈以下结构：

```
                    祁欢（县长）
                        │
            ┌───────────┼────────────┐
            │           │            │
        王相月(常务)  温晓飞(主任)  其他副县长
            │
     ┌──────┼──────┐
     │      │      │
  发改  财政  金融
```

**王相月**作为常务副县长，是县长的首要副手，分管领域最广（发改、财政、
金融、应急等11个领域），并联系人大、政协、监察委、开发区等核心机构，
是政府内部承上启下的枢纽角色。

**温晓飞**作为县政府办公室主任，协助县长处理政府日常工作，是县长与
各副县长之间的信息流转节点。

**段希斌**与**桑越峰**之间存在协助关系（段希斌协助桑越峰分管生态环境），
体现了副职之间的横向协调。

**待加强点**：缺少县委领导信息（县委书记、副书记、纪委书记等），导
致无法构建完整的"县四套班子"网络。

### 穿越与交叉关系

目前收集到的均为政府内部工作分工关系，属于"组织制度规定"的关系类型，
强度等级为"confirmed"但方向单一（上下级关系）。如果有机会获取各方
领导的早期履历，可进一步挖掘：

1. 祁欢与各副县长是否有过同系统/同单位的共事经历
2. 各位领导是否为安阳本地干部（本地成长 vs 交流任职）
3. 是否有同校/同乡等其他类型关系
