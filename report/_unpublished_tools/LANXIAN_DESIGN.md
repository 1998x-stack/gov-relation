# DESIGN.md — 岚县跨县干部交流网络情报简报

## Design Direction
Dark-mode "intelligence dossier" aesthetic. Classified briefing document feel.

## Tokens
- Background: #0A0A0A (near-black)
- Surface: #141414
- Card surface: #1A1A1A
- Border: #2A2A2A (hairline 1px)
- Text primary: #EDEDED (warm off-white)
- Text secondary: #8B8B8B
- Accent - cinnabar red: #E03C31 (used sparingly like seal stamp)
- Confirmed connection: #C9A94E (gold)
- Header serif: "Noto Serif SC", serif
- Body: system-ui, sans-serif
- Border-radius: none (0px) to 4px max
- Deck: max-width 1200px, centered

## Typography
- H1: Noto Serif SC, 2rem, bold
- H2: Noto Serif SC, 1.3rem, semi-bold, gold accent
- Body: 0.9rem, system-ui, #EDEDE0
- Stats: large gold numbers with small labels
