## 3. 跨县干部交流模式分析（基于已知广元市特点）

### 3.1 广市跨县交流一般规律

根据四川省干部交流惯例分析：
- **县委书记**普遍实行**异地任职**（广元籍干部不在广元本县任县委书记）
- **县长**同样多数非本县籍，但从广元其他县提拔的情况常见
- **县委副书记**、**常务副县长**等关键岗位常由广元市下派或外县调入
- 广市所属7县区的干部交流较为活跃，特别是利州区（广元市中心区）与各县之间

### 3.2 已知跨县流动方向（推测）

```
利州区（中心区）↔ 各县
  ├── 广元中学院 → 各县（补给管理干部）
  ├── 各县优秀教委 → 利州区提拔
  └── 副市级干部常从县区委书记中产生
  ├── 苍溪县 ↔ 旺苍县（相邻、经济结构相似）
  ├── 剑阁县 ↔ 旺苍县
  └── 青川县 → 旺苍县（较远县之间交流较少见）
```

### 3.3 跨县交流典型场景

| 场景 | 说明 | 在旺苍的可能性 |
|------|------|--------------|
| 县区长升任当县县委书记 | 标准仕途阶梯 | 高 — 唐涛即为典型（县长→县委书记） |
| 县委书记调任其他县或市直部门 | 平级调动或转任市政府秘书长/副市长 | 高 — 通常3-5年调整 |
| 县调整干部调往企业（如川师大研究所 | 升学经历或挂职 | 中 |
| 省部门直接任命县长 | 省委下派 | 低中 |
| 广元市组织部副部长或市直部门领导下调县长 | "基层锻炼" | 中 |
