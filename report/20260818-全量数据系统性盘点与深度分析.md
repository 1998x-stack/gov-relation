## 4. 深层域分析（本次挖掘）

### 4.1 “一把手”轮换链与晋升链
- 从 relations + org 提取到完整 keep 链（例）：谯城区政府 宋保众→周霄→张建影(2020-2026)、亳州 杜延安→汪一光、合肥 罗云峰→凌云、六安、安庆等，均含 4-6 条连续继任边。
- **132 名干部同时拥有"政府正职(县长/区长/市长)"与"党委正职(书记)"任职轨迹**（如 陈竞、吕志成、赵永刚、韦朝晖、肖福凌）→ 典型的县区→一把手晋升通道。
- 高连通“班子中心” hub：曹立强 19（上海徐汇区委书记）、陈锡明 18（福建浦城）、陈竞 16（长沙市委）——多为"主要领导-班子全员"放射式连接。

### 4.2 关系网络结构
- 关系以 `overlap`（共事）+ `superior_sub`（上下级/主官）为主 + 少量前任继任；网络 = **以现任主官为中心的班子图**。
- 机构内稠密聚类：中共鄂州市委（62 边）、原阳县、焦作、自贡、宁乡（10+)等——班子全体互连。
- 跨省调任落库样例：范波（自贡→山东）、林旭阳（莆田→重庆）、李 俊杰（北京→安庆）等；可支撑跨省链条。

### 4.3 跨区/跨县交流信号
- report 标题含“交流/跨县”：**46 份**；persons JSON 含跨省/交流：**151 份**；positions 标注“跨省/调任”：40+ 条。
- **结论**：跨区流动是价值最高的子主题，但数据中多为“仅文字标注”，需从档案进一步做图谱还原。

### 4.4 纪律/风险信号（quality）
- `risk_and_integrity_signal` 共 5,455 条；其中 **高可信**：
  - 违纪/纪律处理 **discipl. action 30**（如 张智全、郭永航、王莉霞、孙绍骋、韦琪、刘学平、符勇等）；
  - 巡视反馈 **19**；争议 **8**；境外制裁 **1**；其他 ~5,378 为“暂未发现负面”。

> 提示：约 5,400 条 `none_found` 属“采集时点未检出”，非静态“清白”——需要通过持续追踪保持。

### 4.5 开放问题（gap）

## 7. 批量入库记录（2026-08-18 晚，用户指令执行）

### 7.1 做了什么
- 新增驱动 `scripts/tools/batch_promote_tmp.py`：遍历全部 **743** 个 `data/tmp/<task>/`，复用 `process_tmp` 的校验规则，但改为**内容安全**策略：
  - 目标不存在 → 复制（new）；
  - 目标存在且字节一致 → 跳过（不重写）；
  - 目标存在但内容不同 → **跳过并记录冲突**（绝不静默覆盖正库）；
  - 非法/无法识别文件 → 跳过保留在 tmp。
- 随后 `python3 scripts/govdb.py build --database data/platform/gov_relation.db --replace` 重建统一平台库。
