## 1. 概述

云县位于云南省西南部、临沧市中部偏东，是临沧市的交通枢纽。祥临公路、云凤公路、羊耿公路在云县交汇。全县面积约3760平方公里，人口约47万，以汉族、彝族、傣族、白族等民族为主。

云县与 **6个邻县** 接壤：

| 邻县 | 方位 | 距离云县县城(km) | 特殊性 |
|------|------|------------------|--------|
| 凤庆县 | 东北 | ~30 | 地理最邻接、文化同源 |
| 临翔区 | 南 | ~60 | 临沧市政府驻地 |
| 永德县 | 西南 | ~100 | 内地县→边境过渡 |
| 镇康县 | 西 | ~160 | 边境县（接缅甸） |
| 耿马傣族佤族自治县 | 西/西南 | ~120 | 边境县（接缅甸） |
| 双江拉祜族佤族布朗族傣族自治县 | 南 | ~75 | 自治县 |

## 3. 跨县交流通道分析

### 3.1 云县 ↔ 凤庆县（最强关联）

凤庆与云县堪称临沧市"兄弟县"，两县地理紧邻，历史上同属顺宁府，是干部交流最频繁的通道。

**典型模式**：
- **主要领导对调**：云县书记/县长 ↔ 凤庆书记/县长，一般相隔1-2届
- **副县长互调**：云县副县长 → 凤庆县常委/副县长；凤庆县副县长 → 云县常委/副县长
- **关键岗位交流**：组织部长、纪委书记、政法委书记等岗位常跨县交流

**可能涉及的人物（待验证）**：
- 凤庆县近年书记 → 云县的信任（凤庆县书记通常任期满后调云县或市直）
- 云县副县长 → 凤庆县是否按对调模式
- 凤庆县乡镇干部流入云县

### 3.2 云县 ↔ 临翔区（南向升迁通道）

临翔区是临沧市委、市政府驻地，干部从县调入区通常意味着晋升。

**典型路径**：
```
云县县长 → 临翔区长 → 临沧市政府副市长
云县县委常委 → 临翔区委常委（挂职/平调）
```

**已知模式**：临沧市常见从"四县"（云县、凤庆、永德、双江）选拔县长调任临翔长的窗口期。

### 3.3 云县 ↔ 永德县

永德县与云县同属临沧中部区域，二者之间有云永公路直接连接。两县地理接近，干部交流规律接近凤庆—云县模式，但频率较低。

### 3.4 云县 ↔ 镇康县、耿马县（边境轮换）

镇康县和耿马县是云南省边境县，干部配置规律特殊：

- **边境经历加分**：云南省规定县级干部应有一定边境工作经验，云县干部调入后再调回市直是常见晋升路径
- **轮换周期**：一般2-3年一轮换
- **特殊岗位**：边境县委副书记、政法委书记、乡镇党委书记从非边境县调入的现象常见

### 3.5 云县 ↔ 双江县

双江（全称：双江拉祜族佤族布朗族傣族自治县）与云县之间主要是技术性干部交流（教育、农业、扶贫、乡村振兴等业务领域）。

## 5. 临沧市干部交流整体模式

### 5.1 边境-非边境轮换制度

云南省自2010年代起强化边境县干部配置。临沧市有 3个边境县（镇康、耿马、沧源）和 5个非边境县区（临翔区、云县、凤庆县、永德县、双江县）。

边界县与非边境县之间的主要干部定期交流，是云县干部的主导性流动方向之一。

### 5.2 标准干部晋升阶梯

```
1. 乡镇党委书记 → 县直局/副县长 → 县委常委 → 县长 → 县委书记
2. 市直部门副职 → 县县长/县委副书记 → 县委书记 → 市委常委/副市长
3. 省级机关副处 → 县副县长/县委副书记（挂留） → 回省/留任
```

### 5.3 跨市/省交流

临沧市官的跨市调出方向：
- **临沧→昆明**：省厅晋升
- **临沧→大理/保山**：滇西区域内轮岗
- **临沧→普洱/西双版纳**：同属滇西南区块
- **援派/挂职**：上海（崇明区结对）、省直等部门
