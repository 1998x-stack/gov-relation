## 7. 工作管理网络分析

### 7.1 核心搭班关系

```
黄国钧（书记）─←配合→ 蒋涛 （区长）
    │                        │
    ├─陈春梅（专职副书记）      ├─陈旭（常务副区长）
    ├─李轶绪（组织部长）        ├─潘钢刚（兼任常委）
    ├─厉光明（纪委书记）        └─其他副区长
    ├─华刚（宣传部长）
    ├─周咸超（统战部长）
    └─秦成业（人武部政委）
```

### 7.2 关键交接点

1. **书记—组织部长**：黄国钧—李轶玮，这是人事权决策核心链路，提任人大副主任级官员的关键通道
2. **书记—政法委书记**：黄国钧—陈春梅（兼任政法委书记），跨警系统和司法系统的工作衔接
3. **区长—常务副区长**：蒋涛—陈旭锋，政府系统执行链核心，陈旭锋全面负责发展改革、交通、应急等具体事务
4. **政法委—公安分局**：陈春梅—孙斌，政法系统令出法随的轴线
5. **书记（常委）—纪委书记**：黄国钧—厉光明，纪律监督与权力平衡系统

### 7.3 兼任幅度大
- 金义新区"一套班子两块牌子"模式，使区委领导同时担任新区干部领导
- 金东区政府副区长大多兼任新区管委会副主任
- 形成典型的**党政合一、统结合**工作模式
