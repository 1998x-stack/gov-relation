### 模式二：班子成员轮岗交流

茂名市委推行县级领导干部交流制度，通常的模式包括:

1. **市直部门↔区县**：市直部门副职调任区县副职（副书记、常委、副县长等）
2. **区县之间**：同一级别的常委/副区县长在茂名市辖内各区间轮岗
3. **区县内部**：从乡镇党委书记提拔至区县副职

**典型路径**（基于广东省常规干部交流制度推测）:
```
茂南区副区长 → 电白区常委/副区长 (跨区平调)
高州市委常委 → 茂南区常委 (跨区平调)
茂名市直部门处长 → 茂南区副区长 (市直→区县)
茂南区乡镇书记 → 茂南区副区长 (区内提拔)
```

### 模式三：从茂名市市级机关调任茂南区

这是"空降"式交流。茂名市的部委办局领导常被派到茂南区任职:

```
茂名市委副秘书长 → 茂南区委副书记/副区长
茂名市财政局副局长 → 茂南区副区长（分管财政）
茂名市委组织部副部长 → 茂南区委常委/组织部长
```

## 六、干部交流制度背景

广东省的县级干部交流主要基于以下制度框架:

1. **《党政领导干部交流工作规定》** - 县级党政正职一般不在其成长地任职
2. **广东省干部交流实施办法** - 粤东西北地区干部交流政策倾斜
3. **茂名市委组织部干部调配规定** - 县处级领导干部在同一职位满5年的应当交流

**对茂南区意味着**：
- 茂南区委书记大概率不是茂名市本地人（回避制度）
- 茂南区区长一般也不在原籍任职
- 茂南区常委班子中应有1-2名从其他区县交流来的干部
- 茂南区与电白区、高州市之间的交流最频繁（地理位置最近）

## 十、总结

1. **茂南区作为市委驻地**，在干部交流中处于"接收端"优势地位——市直部门调任茂南区的频率较高
2. **垂直交流为主**：茂南区与市直部门之间的交流（M1、M6）是最主要的通道
3. **平行交流存在但数据不完整**：茂南区与电白区、高州市之间应有平级干部交流，但具体案例需核实
4. **市委书记多由省直空降**：茂名市近三任书记（庄悦群、袁古洁、许志晖）均非茂名本地成长，反映了广东省对粤西地市主要领导的"省直空降+跨市交流"政策
5. **市长亦为省直空降**：王雄飞、庄悦群（曾任市长时）均来自省直系统，说明茂名市的正厅级主官以省派为主
