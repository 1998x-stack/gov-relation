普洱市有 **3个边境县** 接壤缅甸、老挝、越南：

- 江城（老挝、越南双边境）
- 孟连（缅甸）
- 西盟（缅甸）
- 澜沧幅面边境（与缅甸）

地理上普洱西连临沧，东接红河/玉溪，北依楚雄/大理，南邻西双版纳。这一区位决定了其干部交流的 **滇西南-滇中双向通道** 和 **边境-非边境轮换制度**。

## 五、普洱市跨县干部交流模式

### 5.1 市内县际交流典型路径（基于临沧同类分析 + 云南省通用模式）

安全普洱与临浏地理相怜、同为滇西南多民族边境区，干部交流模式高度相似：

1. **非边境县（墨江/宁洱/景东/景谷/镇沅） ↔ 边境县（江城/孟连>澜沧/西盟）**
   - 普洱市3个边境线县
   - 推论：市委通常从非边境县选派干部到边境县任职（<1-3年为限）
   - 边境经历 → 提拔必要条件

2. **县 → 思茅区（市府驻地）晋升**
   - Example: 县长→升任思茅区某一职务 → 市直部门或副市长
   - 思茅区是普洱市"跃龙门"的最后一站

3. **市内县际轮换**
   - 县委书记通常在2-3个普洱县的县之间轮换
   - 县长→县委书记（同一县）→调任另一县县委书记
   - 推论：**张泽忠**（景东书纪）可能之前在其他县（如阳洱/景谷/澜沧）任县长

### 5.2 代表性干部来源-去处路径（推断）

```
路径A（从市外来入）:
省外/云南省外城市 → 普洱市委书记/市长 → 调省里/他市
李庆元（玉溪）→ 普洱市委书记
王刚（昭通大关）→ 普洱市长

路径B（跨市调动）:
临沧 ↔ 普洱（演讲西南区域）
临沧市云县 → 普洱市某县（滇西南区域内部交流）

路径C（边境--非边境轮换）:
景东县副县长 → 澜泧县副书记（边境沉淀） → 景谷县委书记（回流）
```

## 五、现有数据区域间关联线索

### 临沧—普洱跨市通道

根据此前对较多市调研（20260728-临沧官员干部交流网络），临沧与普洱之间干部交流属于 **"滇西南区域内部交流"** ，是代表性省内跨市流动：

```
临沧市（云县/凤庆等） ↔ 滇西南区域内部 ↔ 普洱市（宁洱/景谷等）
                                   ↘ 西双版纳州
```

### 来源： 李庆元（玉溪）和王刚（昭通）的调入普洱

李庆元是玉溪市江川区人，王刚是昭通市大关县（市北部）人。这符合云南省从其他市调入市级主管的策略——**限制本地政治上的利益结盟**。陈化、王鸿彬（景东人）为人大主任，则是一种**为当地本地派留下的职业安排**
