## 三、云县→邻县重点交流通道分析

### 3.1 云县 ↔ 凤庆县（最强链路）

安全**凤庆县**是云县的最紧邻，两地文化同源（同属澜沧江沿岸同语系），经济往来密切，是临沧市内干部交流最频繁的配对路径。

**已知/可能的交流人物**：

| 人物名 | 推测路径 | 置信度 |
|--------|---------|--------|
| 曾担任凤庆县政委/县长 → 云县职务 | 两地主要领导对调 | ⭐⭐ 需确认 |
| 云县副县长 → 凤庆县常务副县长 | 平级调任 | ⭐⭐ 需确认 |

**凤↔云交流的典型模式**：
- **主要领导对调**：县委书记↔凤庆县委书记或县长的交流是临沧市最常见的跨县交流类型
- **相隔一定年限的逆向调**：A县副县长→B县常务副县长→A县县长

### 3.2 云县 ↔ 临翔区（市府方向）

安全距离：临翔区（临沧市政府驻地）与云县紧邻。干部从区县调入临翔区通常意味着进入了市领导视野，可视为**升迁跳板**。

**常见模式**：

```
云县县长 → 临翔区长（区级市）→ 临沧市政府副市长
云县县委常委 → 临翔区委常委
```

| 交流类型 | 方向 | 置信度 |
|---------|------|--------|
| 云县→临翔区 | 从县到区，通常为晋升 | ⭐⭐ 需确认 |
| 临翔区→云县 | 从市辖区到县，任县委书记（降级提权） | ⭐⭐ 需确认 |

### 3.3 云县 ↔ 永德县

在行政级别上，永德县和云县在临沧市处于同一层级  两县之间的交流规律与凤云配对类似，但不如凤庆-云县线路密集。

### 3.4 云县 ↔ 镇康县/耿马县/双江县

镇康、耿马是**边境县**，干部交流涉及边境工作经历加分。

**常见交流路径**：
- 云县干部 → 调入镇康/耿马担任县委副书记（加强边境领导力量）
- 边境县干部调回云县（内区县）
- 市委从非边境县选派干部到边境县晋升一级担任主要领导

### 3.5 云县 ↔ 市直单位/市级部门

**市直→云县（下派）**：
| 常见路径 | 说明 |
|---------|------|
| 市委办公室副主任 → 县委副书记/副县长 | 下派锻炼 |
| 市政府办公室副主任 → 副县长 | 常见路径 |
| 市商务局/发改委副职 → 副县长（援边或经济后位帮扶） |

**云县→市直（提拔）**：
| 常见路径 | 说明 |
|---------|------|
| 县委书记 → 市委常委/副市长 | |
| 县长 → 市直部门局长/主任 | |
| 县委常委 → 市级部门副局长 | |

## 五、临沧市干部交流典型模式

### 5.1 临沧市特有的边境-非边境干部轮换制度

云南省长期运行的以下模式，临沧市执行的典型：

1. **边境县（镇康、耿马、沧源）与非边境县（云县、凤庆、永德）轮换**
2. **市辖区（临翔区）与其他县对调**
3. **彝族/傣族少数民族干部优先安排在自治县**

### 5.2 典型晋升路径

```
路径A：县（县长）→ 市辖区（区长）→ 副市长
路径B：县（县委书记）→ 市委常委/政法委书记
路径C：边远县（副书记）→ 核心县（县长）
路径D：省直/市直下派 → 县（副书记/副县长/组织部长）→ 回市直
```

### 5.3 跨市调入/调出

临沧市县级干部的跨市交流通常指向：
- **临沧→昆明**：省直机关提拔
- **临沧→大理**：滇西地区内部交流
- **临沧→楚雄**：滇中城市群
- **临沧→普洱/西双版纳**：同属滇西南区域
