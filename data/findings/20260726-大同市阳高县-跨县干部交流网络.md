### 3.1 市直部门 ↔ 县区交流

```
市直部门（市委办、组织部、发改委等）↔ 县区主要领导岗位
```

典型路径：
- **市委副秘书长** → **县委书记**（或县长）
- **市政府副秘书长** → **县长**
- **市发改委主任/副主任** → **县长**
- **市委组织部副部长** → **县委副书记/组织部长**

### 3.2 县区之间横向交流

| 常见配对标段 | 模式 | 说明 |

| 阳高县 ↔ 天镇县 | 相邻县之间对调/交流 | 地理相邻，经济结构类似 |
| 阳高县 ↔ 云州区 | 县↔区交流上升通道 | 云州区（原大同县）与阳高县相邻 |

| 广灵县 ↔ 阳高县 | 相邻县 | 同处大同东部 |

## 六、跨县交流模式分析（理论框架）

### 6.1 已知大同市干部交流特征（模式级）

1. **东部县群内部交流**：阳高、天镇、广灵三县地理位置相邻，同属大同东部农业经济区，历史上干部互调频繁
2. **市县双向流动**：从市直机关"下派"到县区任职，再从县区提拔回市直
3. **东西对流**：西部左云县（产煤）与东部各县（农业）之间有"肥瘦搭配"性质的交流
4. **南北对流**：南部浑源、灵丘（山区）与北部各县之间

### 6.2 典型交流模式

```
模式A: 市直→县→市直
  - 市委办副主任 → 阳高县长 → 市局局长

模式B: 县↔县（平行交流）
  - 天镇县长 → 阳高县委书记

模式C: 区→县（重用）
  - 平城区副区长 → 阳高县长

模式D: 县→区（提拔）
  - 阳高县委书记 → 平城区委书记
```
