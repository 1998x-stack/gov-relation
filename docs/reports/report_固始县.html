1. 现任县委书记：杨浩威（完整履历）

身份: 男，汉族，1981年6月生，河南临颍人，2006年5月入党，研究生学历、管理学博士（东南大学）。2009年9月参加工作（博士引进）。

完整履历（百度百科/快懂百科确认，source S001/S002）:

  • 1999-2003 河南师范大学 信息管理与信息系统（管理学学士）
  • 2003-2006 中共江苏省委党校 企业管理（管理学硕士）
  • 2006-2009 东南大学 管理科学与工程（管理学博士）
  • 2009-2010 息县包信镇 工作（引进博士）
  • 2010-2011 息县包信镇党委副书记（正科）
  • 2011-2012 息县包信镇党委副书记（副处级）
  • 2012-2016 息县人民政府党组成员/副处级干部
  • 2016-2018 信阳市发展和改革委员会党组成员、副主任
  • 2018-2020 信阳市平桥区委常委、副区长
  • 2020-2021 信阳高新技术产业开发区党委副书记、管委会主任
  • 2021-2022 固始县委副书记、副县长、代县长
  • 2022-2023 固始县人民政府县长
  • 2023-2023.09 固始县委书记兼县长、县人武部党委第一书记
  • 2023.09-至今 固始县委书记、县人武部党委第一书记

晋升路径: 博士下基层（包信镇）→息县→信阳市直（发改委）→平桥区→信阳高新区→固始县长→县委书记。跨乡镇-县-市-开发区-县委多重体系，属技术型（管理学博士）+综合发展能力干部。

2. 现任县长：李新民

  • 男，汉族，1976年8月生，河南新县人，党校大学，1996年9月参加工作，中共党员。
  • 曾任固始县委常委、常务副县长（分管财政金融、优化营商环境、招商引资，2022年在任）。
  • 2023-10-20 固始县十五届人大一次会议当选县长。
  • 履历缺口: 1996-2020 共24年完整职务链未公开（critical gap）。

3. 前任县委书记：王治学（去向）

  • 男，汉族，1968年12月生，信阳新县人，1991-07北京大学哲学系毕业，1995年12月入党。
  • 履历: 信阳文明办→信阳市政府办→浉河区→信阳市政府副秘书长→信阳市委副秘书/政研室主任→光山县长（2011-2014）→固始县长（2014-2021）→固始县委书记（2021-08）→2023-06 卸任。任期间兼信阳市人大常委会副主任。

  • 更早前任: 曲尚英（2021-08 卸任）。
