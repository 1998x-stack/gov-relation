2. 现任县长（代县长）：王孛

  • 男，汉族，1982年6月生，大学学历；2001年9月参加工作，2003年11月入党。
  • 在任：和林格尔县委副书记、县政府党组书记、县长提名人选（代县长），兼任呼和浩特和林格尔乳业开发区党工委书记；主持县政府全面工作并负责审计。

王孛于2026年7月任县长提名人选（代县长），接替转任县委书记的张志魁。

3. 前任县委书记：李六小

  • 男，汉族，1975年9月生，内蒙古呼和浩特市清水河县老牛湾镇人，内蒙古党校大学学历；1998年1月参加工作，2000年4月入党。
  • 履历：清水河县委办、城关镇 → 2020年2-12月赛罕区委常委、组织部部长 → 2020年12月任和林格尔县县长候选人 → 2021年1月任副县长/代理县长 → 2021年5月任县委书记 → 2025年后调任呼和浩特市国防动员办公室（党组书记、一级调研员）。

更早前任县委书记：张永文。

4. 前任县长：高峰

  • 蒙古族，1973年4月生，呼和浩特市土默特左旗人；2024年5月因工作调整辞去和林格尔县县长职务，由张志魁任代理县长接续。
