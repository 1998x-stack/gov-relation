6. 关键人物简历

冯锐（县委常委、常务副县长）

  • 1979年4月生，陕西山阳县人，经济管理研究生学历
  • 历任：山阳县政府办副主任科员 → 山阳县委办公室副主任、县委调研室主任 → 山阳县漫川关镇党委副书记、镇长 → 山阳县漫川关镇党委书记 → 山阳县政府党组成员、漫川管委会主任 → 镇安县委常委、宣传部部长 → 柞水县委常委、县政府副县长
  • 关键发现： 冯锐是跨县交流干部，曾在镇安县担任县委常委，与同样来自镇安县的蒋维杰有地缘和工作交集

李浴溱（县委常委、副县长）

  • 1970年10月生，本科学历
  • 柞水本地成长型干部，全部职业生涯在柞水县
  • 历任：柞水县委保密局副局长 → 柞水县政府办公室副主任 → 柞水县人民政府督查督办室主任 → 柞水牛背梁森林公园筹建处主任 → 陕西牛背梁国家森林公园管委会主任 → 副县长 → 县委常委、副县长

王书华（挂职县委常委、副县长）

  • 1971年11月生，河北衡水人，博士研究生
  • 享受国务院特殊津贴专家
  • 历任：河北师范大学讲师 → 清华大学水利工程系博士后 → 中国科学技术发展战略研究院副研究员、研究员，历任多个研究所所长 → 院务委员、院党委委员 → 挂职柞水县委常委、副县长
  • 特殊背景： 来自北京中央部委研究机构，是典型的"央地交流"挂职干部

王宁（副县长）

  • 1970年6月生，回族，研究生学历
  • 曾任镇副镇长、副书记、镇长、书记，街道党工委书记，市直部门副职
  • 履历信息较模糊

李小军（副县长、公安局长）

  • 1977年4月生，本科学历
  • 全部职业生涯在商洛市公安局
  • 历任：商洛市公安局办公室副主任 → 办公室主任 → 二级警长、一级警长 → 柞水县政府副县长、公安局局长

  • 全部职业生涯在镇安县
  • 历任：镇安县人民政府副科级研究员 → 镇安县东川镇党委副书记、镇长、党委书记 → 镇安县云盖寺镇党委书记 → 柞水县政府副县长
