6. 工作关系网络分析

党政一把手

  • 常波（书记）↔ 赵明（区长） = 当前党政搭档；前任身份为常波前任书记/赵明前任区长（跨岗位接替）。[confirmed]

政府领导班内（核心共事关系）

  • 区长 ↔ 常务副区长；区长 ↔ 7位副区长：政府领导班子同舟共济（区有位任职、任期重叠）。[confirmed structure]

跨区交流网（官方履历佐证，[confirmed]）

  • 薛英辉：铁东区叶赫满族镇/山门镇/区信访 → 铁西区副区长 → 回铁东区副区长：铁东↔铁西 双向干部轨道。
  • 岳楠：四平市扶贫办 → 双辽市王奔镇 → 铁东区副区长：双辽→铁东。
  • 上阻：铁东区区长（赴申县历练后回）。
  • 杨嘉龙：伊通县靠山镇/莫里青乡 → 铁东区副区长：伊通→铁东。
  • 田枫：市政府办公室系统务→ 铁东区常务副区长：市→区。

结论：四平市区（县）间干部交流是干部培养的主渠道，尤以 铁东/铁西（同城）、双辽/伊通（周边县市）为主；结构特征为「市直机关或周边县 → 铁东区」。
