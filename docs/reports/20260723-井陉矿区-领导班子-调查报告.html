概述

井陉矿区是河北省石家庄市下辖的一个市辖区，位于石家庄市西部。本次调查聚焦该区现任党政主要负责人——区委书记刘杰和区长郭贺伟，以及区级领导班子成员。

调查日期: 2026-07-23

数据来源: 井陉矿区人民政府门户网站（www.sjzkq.gov.cn）矿区要闻、区委全会新闻报道、巡视整改通报

6. 工作关系网络分析

确认的交集

  1. 刘杰 ↔ 郭贺伟（强关系）: 区委书记与区长是全区党政领导核心，共同主持经济高质量发展大会等全区性会议，存在清晰的党政正职搭档关系。
  2. 刘杰 ↔ 殷蓓（强关系）: 区委书记与区委副书记，在同一区委常委会班子工作，共同参加各类会议，已持续至少1年以上。
  3. 刘杰 ↔ 李建义 / 任玉玉（中强关系）: 区委书记与人大主任、政协主席构成区级四套班子关系。
  4. 郭贺伟 ↔ 殷蓓（强关系）: 区长与区委副书记在区委常委会中直接协作。

强弱关系分类

  • 强关系（区委常委会内部）: 刘杰-郭贺伟-殷蓓三人核心
  • 中强关系（四套班子）: 三人分别与李建义、任玉玉
  • 待发现关系: 其他区委常委与上述核心人物的交叉关系

7. 周边县区人事交流网络

待查: 井陉矿区与周边区县（井陉县、鹿泉区、平山县等）之间是否存在干部交流，需进一步研究。井陉矿区是石家庄市面积最小的市辖区之一（约70平方公里），由原井陉县矿区部分划出设立，历史上与井陉县关系密切，值得关注两区县间是否存在干部交叉任职。

8. 关键洞察与突破线索

核心发现

  1. 领导核心稳定: 刘杰自2025年8月已任区委书记并至少持续至2026年7月，领导基础牢固。
  2. 发展定位明确: "省会城市美丽'后花园'"是井陉矿区的核心发展定位，产业转型（冶金新材料装备制造）是工作重点。
  3. 区情特点: 井陉矿区是典型的资源型城市（煤矿）转型区，面积小但级别完整，区委和区政府有完整的四套班子配置。

待破解的关键缺口

  1. 刘杰和郭贺伟的完整履历: 二人此前的职务轨迹完全未知，这是理解其工作网络的最大障碍。
  2. 区委常委完整名单: 缺乏纪委书记、组织部长、宣传部长、政法委书记等关键常委的个人信息。
  3. 前任领导去向: 刘杰担任区委书记前，井陉矿区的书记是谁？去了哪里？这一缺口导致无法追溯干部交流路径。
  4. 跨区交流线索: 井陉矿区与井陉县原本同属井陉矿务局管理体系，可能存在干部交叉。
