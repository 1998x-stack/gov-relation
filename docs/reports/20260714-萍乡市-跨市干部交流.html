二、已确认的萍乡跨市干部交换模式

2.1 模式一："赣西环线" — 宜春↔萍乡↔景德镇↔上饶↔宜春（颜赣辉闭环）

核心人物：颜赣辉 — 这是赣西环线最典型的案例。

颜赣辉的完整路径：

```

宜春市委常委/副市长(2005.01–2011.08)

→ 萍乡市委副书记(2011.08–2013.09) ← 萍乡节点

→ 景德镇市长(2013.09–2016.04)

→ 上饶市长(2016.04–2017.06)

→ 宜春市委书记(2017.06–2020.06, 后落马) ← 回到起点

```

确认的事实：颜赣辉在萍乡担任市委副书记（2011.08–2013.09），约2年时间。这构成了"赣西环线"中萍乡段的明确连接。

源: https://zh.wikipedia.org/wiki/颜赣辉

2.2 模式二：景德镇↔萍乡↔宜春"旋转门"

人物路径性质
邓保生景德镇市委书记(2011–2013) → 宜春市委书记(2013–2017)跨市平级调动
郭安宜春→景德镇市委常委/常务副市长(2009–2011)→南昌→鹰潭经景德镇中转

说明：邓保生从景德镇书记转任宜春书记，跨越了"景德镇—宜春"轴线。萍乡位于宜春西侧，与这一轴线地理相邻。

说明：萍乡市长线也呈现类似特征。刘烁先后任市长(2021–2023)→书记(2023–2026)，路径与景德镇的陈克龙类似。

2.4 模式四：萍乡↔吉安（南部连接）

最新案例：

  • 傅正华（2026年5月任萍乡市长），籍贯吉安县。其从吉安体系调任萍乡，构成"吉安→萍乡"的南向通道。

2.5 模式五：跨省交流（萍乡↔湖南）

萍乡地处湘赣边界，西接湖南株洲、长沙。虽然搜索受限，但结合历史：

  • 萍浏醴起义等历史渊源说明萍乡与湖南浏阳、醴陵有深层民间和产业联系
  • 萍乡到长沙黄花机场约120km，到宜春明月山机场约60km，经济联系偏向湖南
  • 待查：是否有厅级干部在湘赣之间直接调任

三、周边城市交叉验证

3.1 张智萍（新余/宜春/吉安反复调动）

张智萍的路径（据新余报告）：

```

新余(分宜县) → 宜春(宜丰县长) → 吉安(遂川书记) → 新余(人大主任)

```

这是赣西三市（新余、宜春、吉安）之间罕见的跨市反复调动案例。与萍乡的关联：分宜县历史上曾属宜春、萍乡均有密切经济往来。

3.2 新余市的萍乡连接

新余报告确认：新余作为"接收型城市"，主要从省直空降（方向军、郑光泉、犹㼆均为省直来源），与萍乡的直接干部交流极少。新余与邻居宜春、吉安之间的平级干部交流同样较少。

萍乡在其网络中的角色

颜赣辉的萍乡任职（市委副书记）是其从宜春副市长到景德镇市长的 "跳板" 。在萍乡的2年副书记经历，帮助他完成了：

  1. 从副厅级（宜春副市长）到正厅级（景德镇市长）的跨越
  2. 从赣西（宜春/萍乡）到赣东北（景德镇/上饶）的地理区域切换
  3. 积累地级市核心领导经验

这个路径成为"赣西环线"假说最有力的支撑。

六、关键洞察与优先线索

⭐⭐⭐⭐⭐ 第一优先

  1. 余正琨的完整履历 — 新任萍乡书记（2026.5到任），其前任职务、籍贯、早期生涯均需查实，是判断当前萍乡人事格局的第一关键
  2. 傅正华的完整履历 — 新任市长（2026.5到任），吉安籍贯，是否从吉安体系直接调任？如果是，则"吉安→萍乡"通道被强化

⭐⭐⭐⭐ 第二优先

  1. 刘烁的去向 — 2026年5月卸任萍乡书记后去向不明。其前任陈敏升任副省长，刘烁是否类似升迁？

  3. "赣西环线"是否有其他人物 — 除颜赣辉外，是否还有其他官员走过宜春→萍乡→景德镇→上饶→宜春的完整闭环？

⭐⭐⭐ 第三优先

  1. 萍乡与湖南的跨省交流 — 萍乡西接湖南株洲，历史上萍浏醴联系紧密。是否有湘赣两省之间的厅级干部直接调任？
  2. 李小豹落马的涟漪效应 — 前书记李小豹（2023年被查）是否影响了萍乡后续人事安排？
