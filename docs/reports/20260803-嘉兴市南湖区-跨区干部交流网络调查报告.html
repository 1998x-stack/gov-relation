一、嘉兴市行政区划背景

嘉兴市下辖2区、3县级市、2县：南湖区、秀洲区、海宁市、平湖市、桐乡市、嘉善县、海盐县。

南湖区是嘉兴市委、市政府驻地，嘉兴市政治、经济、文化中心，原名秀城区，2005年改为现名。

四、跨区交流模式分析

模式1：市委书记→杭州/省级

嘉兴是浙江省地级市，其市委书记多升仕至杭州（副省级市市委书记）、浙江省政府（副省长）、或跨省晋升（如卢展工→福建）。

模式2：区县与地级市之间的干部流通

嘉兴市本级干部向辖区调配的典型路径：

  • 嘉兴市副市级干部→下辖县（市、区）任主要领导
  • 下辖县主要领导→嘉兴市直部门或市政府副市长

模式3：嘉兴市内部7个县市区之间的交流

已知交叉实例（待系统验证）：

  1. 陈利众（嘉兴市政协主席）：籍贯平湖市，职业生涯高度集中在嘉兴系统内，属"本土晋升型"
  2. 鲁俊（前嘉兴市委书记/市长）：市长→市委书记（本地晋升）

模式4：跨地级市交流

嘉兴市领导调往外市的案例：

  • 王国平 → 杭州市委书记
  • 黄坤明 → 杭州市委书记
  • 张兵 → 此前为丽水市领导（异地调入）

六、关键洞察

  1. 南湖区居核心地位（存在信息不对称问题）：作为嘉兴市委驻地，南湖区是全市干部交流的固然中心——但目前缺少历届区委书记/区长的完整信息，无法构建立体交流图
  2. 嘉兴市委书记任后多数"高升"：近30年嘉兴书记升副部比例高，外派方向以浙江省委/杭州/省级为主
  3. 大部分跨区信息中最显著疑问：南湖区（区委书记、区长空缺匹配不完全）仍是一个关键缺口
  4. 初步结论：嘉兴市干部跨区交流以市→省/市→副省级城市为主，县市区之间的""内循环"交叉信息存在于公开档案中但系统收集不足
