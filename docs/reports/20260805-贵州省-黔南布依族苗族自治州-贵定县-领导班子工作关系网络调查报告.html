六、工作关系网络分析

核心确认交集：

  • 仲成鹏 ↔ 黄祖方：县委书记与县长搭档（strong，2026年在位）。
  • 仲成鹏 ↔ 杨奕 / 刘永祥：县委书记与两位县委副书记（强）。
  • 仲成鹏 ↔ 王伟超：县委书记与前任县长曾在县委县政府班子共事（中）。
  • 黄祖方 ↔ 王伟超：县长继任（successor，强）。
  • 黄祖方 ↔ 县政府若干副职：县长与副职在多个专题会、开发区管委会共事（中）。

强弱关系定义：强 = 直接上下级搭档 / 前后任关系；中 = 同班子共事；弱 = 仅同台执行主席等无直接运营交集。

七、周边县区人事交流网络（待展开）

贵定县隶属黔南州。黔南州县级领导干部多经州直机关轮转或跨县交流。仲成鹏、黄祖方均于2026年新任现职，任前来源与是否自州直/邻县调入尚未确认，跨县调动时点列开放疑问。

八、关键洞察与突破线索

  1. 书记县长均属新任：仲成鹏与黄祖方均于2026年任现职，黄更由代理县长转正仅月余，属新一轮县级人事布局。
  2. 经济主引擎 = 昌明经济开发区：国家绿色园区、外贸提升区，书记与县长分别兼任党工委书记/管委会主任，显示重工业、重企业、重招商引资的治理取向。
  3. 发展热点与短板并存：政府工作报告提示产业投资与民间投资活力不足、教育医疗资源不足；县域治理、教育大会筹备为2026年热点任务。
  4. 东西部协作紧密：与广州海珠区、南沙区深度协作，共建"海珠·贵定"园区，属东西部协作重点县。
