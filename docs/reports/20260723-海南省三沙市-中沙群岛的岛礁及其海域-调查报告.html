中沙群岛的岛礁及其海域 领导班子工作关系网络调查报告

核心发现

中沙群岛的岛礁及其海域没有独立的区委/区政府领导班子。

2020年4月18日，国务院批准三沙市设立西沙区、南沙区两个市辖区，未单独设立中沙区。中沙群岛的岛礁及其海域在行政上由西沙区代管。

1. 行政区划现状

背景

  • 三沙市成立于2012年7月24日
  • 2020年4月18日，国务院批准设立西沙区和南沙区
  • 中沙群岛区域由西沙区代管，不设独立行政管理机构

地理概况

  • 中沙群岛位于西沙群岛东南约100公里
  • 由20多个暗礁、暗沙和暗滩组成
  • 唯一露出水面的岛礁：黄岩岛（又名民主礁，Scarborough Shoal）
  • 主要地貌：中沙大环礁（长140km，宽55km，水深9-26米）
  • 无常住居民，由海警巡驻

三沙市下辖治理结构

```

三沙市

├─ 西沙区（管辖西沙群岛，代管中沙群岛）

│ └─ 中沙群岛的岛礁及其海域（由西沙区代管，无独立班子）

├─ 南沙区（管辖南沙群岛）

└─ 永乐工作委员会（永乐群岛区域管理派出机构）

```

6. 关键洞察

  1. 无独立班子：中沙群岛的岛礁及其海域是全国极少数没有独立党政领导班子的"市辖区"之一，类似于统计用区划代码而非实体政府
  2. 西沙区代管：实际的行政管辖权在西沙区，最终决策在三沙市层面
  3. 军事化管理：黄岩岛等关键岛礁由海警实际巡驻，行政管理以间接方式实现
  4. 三沙市总量小：全市常住人口仅2333人（2020年普查），中沙区域无常住居民，不设独立行政机构符合实际情况
