7. 周边县区人事交流网络

七台河市区划格局

七台河市下辖三区一县：桃山区、新兴区、茄子河区、勃利县。勃利县是唯一的县，其余为城区。

已知的交流模式

1. 桃山区 → 勃利县

  • 张生河的职业生涯前20年全部在桃山区（桃西乡→万宝河镇→兴岗街道→桃西街道→桃山供水处→汽车公司），2022年才调任勃利县
  • 这是本调查中最重要的跨区县交流线索

2. 七台河市直 → 勃利县

  • 张生河从市人社局长调任勃利县长（2022年）
  • 王华锋极可能也来自七台河市直机关或另一县区（待查）

3. 历史沿革

  • 勃利县原辖现今茄子河区的部分地域（1965-1966年七台河特区从勃利县析出，茄子河、中心河等划归特区）
  • 这一行政调整形成了长期的人事流动通道

4. 全市主要领导

  • 市委书记：陈延良（从省教育厅副厅长调任，非七台河本土成长）
  • 市长：张涛（~2024年12月到任）
  • 两人均为外地空降，说明市级班子有较强的省级统配特征
