摘要

嵩县（隶属河南省洛阳市）现行党政主官为：

  • 县委书记：辛俊峰（男，汉族，1975 年 11 月生，大学/省委党校大学学历，法律专业，中共党员）
  • 县委副书记、县长：任庆鹏（男，汉族，1987 年 3 月生，河南新乡人，北京大学生命科学学院生物化学与分子生物学专业博士研究生，中共党员）

两人构成"老党员县级班底 + 北大博士技术干部"的搭配。辛俊峰按"洛阳市副秘书长 → 嵩县县长 → 嵩县县委书记"的典型县域晋升路径快速登顶；任庆鹏则为受过高等科研训练的技术型干部，由科技创新园区系统转入县级政府系统，并经历伊川县→嵩县的跨县调动。

4. 前任县委书记（去向）

宗玉红（女，汉族，1966 年 5 月生，河南洛阳人，大学学历，中共党员），现任洛阳市政协副主席。

  • 历：洛阳市瀍河回族区司法系统 → 洛宁县政府副县长 → 洛阳市妇联副主席 → 中共栾川县委（宣传/政法/常务副县长/副书记）→ 嵩县县长（2014-09 至 2021-07） → 嵩县县委书记（2021-07 至 2023-05） → 洛阳市政协副主席（2022-02 起兼任，2023-05 起专职）。
  • 去向：2023-05 卸任嵩县县委书记，专职任洛阳市政协副主席，并连续任嵩县县长/书记 9 年期间曾获"河南省脱贫攻坚先进个人"（2021-05）。
  • 与现书记交接：2023-05-22 辛俊峰接任县委书记。

前任县长即辛俊峰本人（2022-04 至 2023-12）；任庆鹏 2023-12 接任县长。因此嵩县的书记与县长两条权力线均经历清晰的"县内晋升 + 跨县调入"交接。

8. 关键洞察与突破线索

  1. "高知县长 + 老党员书记"：任庆鹏（北大博士、1987年）与辛俊峰（省委党校大学、1975年）形成鲜明的代际与学历反差，是值得关注的政绩化搭配，嵩县未来可能在科技创新、园区经济方向发力。
  2. 跨县网络枢纽：嵩县是洛阳市多个县区主职领导的"初始地"（伊川县委书记王智朋在嵩县工作 18 年；伊川县长仝宇鹏、前任伊川书记仝宇鹏均在嵩县多年），而任庆鹏又从伊川调入嵩县长——嵩县↔伊川 show 双向交流。
  3. 宗玉红的长链条：瀍河→洛宁→栾川→嵩县→洛阳市政协副主，展现洛阳基层县委书记"多县轮岗→市级"典型路径，可追踪其历任搭档关系。
  4. 后续重点：查实辛、任 2017 年之前的早期履历，以及各常委完整履历，将补全整张既有网络。
