6. 工作关系网络分析

核心发现：四连传的"县长→书记"传承链

阳曲县自2016年以来形成了极其稳定的内部晋升传统：

```

刘晋萍(县长) → 裴耀军(县长) → 李京京(县长) → 姬发军(县长)

↓ ↓ ↓ ↓

刘晋萍(书记) → 裴耀军(书记) → 李京京(书记) → 姬发军(书记) → 吴英志(现任县长)

```

连续四任县委书记均从本县县长岗位提拔，这在山西县级政治中较为罕见，说明阳曲县存在稳固的内升机制。

去向模式分析

县委书记卸任去向评价
刘晋萍吕梁市副市长→市委常委（跨市）跨市晋升，副厅级
裴耀军太原市人大副主任→市委常委/秘书长→常务副市长→省工商联党组书记稳步晋升至正厅级
李京京清徐县委书记（平调）唯一平调，但清徐经济地位更高

吴英志的跨界调动

吴英志从清徐县委常委→阳曲县委常委→阳曲县委副书记→县长，属于县际交流的典型案例。

关键结论：

  • 阳曲是太原市干部的重要历练平台，担任阳曲县委书记后多获晋升
  • 姬发军是唯一的"回流"案例（从阳曲副县长调出后又回到阳曲担任主官）
  • 清徐与阳曲之间存在频繁的干部交流（裴耀军、吴英志均与清徐有关联）

8. 关键洞察

  1. 稳定的内升传统：阳曲县长几乎必然晋升为县委书记，这可能固化利益格局
  2. 阳曲作为跳板：阳曲县委书记卸任后多获得实质晋升（刘晋萍→吕梁副市长，裴耀军→太原市领导→正厅级）
  3. 姬发军"一肩挑"的特殊性：2025年4月至12月，姬发军同时担任书记和县长，这是过渡期的安排
  4. 吴英志的源头：作为北京出生但却在太原市基层成长的干部，吴英志的晋升路径值得关注
  5. 孙晋生落马案：阳曲县原副县长孙晋生（娄烦人）因严重违纪违法被双开，显示当地存在廉政风险
