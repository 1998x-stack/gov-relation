1. 现任市委书记：姚华明

身份：男，汉族，1971年10月生，1992年6月入党，1994年7月参加工作。全日制大学学历（北京外国语大学文学学士），在职研究生学历（法国巴黎第一大学公共管理硕士）。

晋升路径：

  • 1994–2021：中国银行系统27年。历任办公室秘书一处副处级秘书 → 巴黎分行展业部副经理/公司业务部经理 → 公司业务部主管 → 公司金融总部主管/助理总经理 → 北京市分行行长助理/副行长 → 中银香港人力资源部总经理 → 宁波市分行党委书记/行长 → 深圳市分行党委书记/行长。（confirmed）
  • 2021：任营口市委常委（正厅级）、副书记（央企转地方政务）。（confirmed）
  • 2021.8–2022.1：任营口市代市长。
  • 2022.1–2024.5：任营口市市长。（confirmed）
  • 2024.5–至今：任营口市委书记；2024–06 起兼营口军分区党委第一书记。（confirmed）

兼社会职务：中共辽宁省第十三届委员会委员，辽宁省第十四届、第十四届全国人大代表。

治理画像：金融系统背景深厚，主抓"4+4+N"现代化产业体系、"六张网"基础设施、政银企协同；强调"解题思维""十五五"开局、安全生产。

2. 现任搭档市长：李军

  • 男，汉族，1970年5月生，研究生学历、硕士，党员。
  • 现任营口市委副书记、市政府党组书记、市长，主持市政府全面工作，分管市审计局。
  • 履历：沈阳市苏家屯区委书记 → 沈阳市委常委、秘书长 → 2023.3 沈阳市委常委、常务副市长 → 2024.5 营口市委副书记、提名为市长，任代市长后转正。（confirmed）
