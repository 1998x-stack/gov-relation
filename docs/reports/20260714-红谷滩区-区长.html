6.3 红谷滩区与东湖区的特殊联系

红谷滩区与东湖区之间存在迄今为止南昌最密集的干部双向交流通道：

```

刘光荣：红谷滩区长 → 东湖区委书记（区长升书记，重用）

李婷：东湖区委常委/副区长 → 红谷滩区长（副职升正职）

邓之武：→ 东湖代区长（填补李婷调离后的空缺）

```

几乎在同一时期，两区的主要领导进行了对调式轮换，表明南昌市委有意在这两个相邻区之间建立干部双向培养通道。

  1. 晋升跳板型节点：刘光荣从红谷滩区长升任东湖区委书记

发现的三种主要交流模式

  1. "旋转门"模式（吴江辉型）：从一个区到另一个区逐级升迁，积累多区经验
  2. "环流升迁"模式（刘光荣型）：跳出原籍→在外历练→回流升任，"跳出培养再回流"模式
  3. "市直空降"模式（涂晓晖型）：市直部门直接空降到区县任一把手

8. 关键洞察与突破线索

🔴 最高优先级

  1. 红谷滩区是南昌干部交流的"旋转门" — 几乎所有主要领导都有其他区县任职经历，是全市干部培养链上的关键节点。
  2. 东湖区—红谷滩区构成干部双向培养通道 — 刘光荣、李婷的双向流动，证明南昌市委将这两个相邻区视为干部轮换的配对单位。
  3. 涂晓晖的去向是重要线索 — 如果涂晓晖确实调往南昌市国资委，则意味着红谷滩区委书记这一职位的"出路"正在向经济管理条线延伸。

🟡 次级线索

  1. 李婷的早期履历是最大信息空白 — 她的职业生涯从~2021年前（约45岁前）几乎完全缺失，但从"基层教师→组织部→副区长→区长"的碎片线索看，她代表了"教育系统→党群系统→政府系统"的跨领域晋升模式。
  2. 万晓娟是红谷滩区任职最久的核心领导 — 自2021年建区以来一直担任区委副书记，是维系红谷滩政权延续性的关键人物。
