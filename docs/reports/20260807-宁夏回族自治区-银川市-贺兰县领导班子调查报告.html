1. 现任县委书记：杨爱军

基本信息：男，汉族，1974年2月生，宁夏灵武人，2000年6月入党，1997年7月参加工作，西北政法大学法律专业大学学历。

履历（confirmed）：

  • 灵武市临河镇党委副书记、镇长
  • 灵武市马家滩镇党委书记、人大主席
  • 银川市纪委办公室主任
  • 银川市西夏区委常委、纪委书记、监察委员会主任（注：一份任前公示记载为兴庆区，属待核实矛盾）
  • 2021.09–2022.12 银川市监察委员会副主任
  • 2022.12–2024.04 银川市司法局局长
  • 2024.04–2025.08 银川市审批服务管理局局长
  • 2025.08 至今 贺兰县委书记（2025.08.11全县领导干部大会宣布，2025.09兼任县人武部党委第一书记）

职业画像：纪律检查/监察→政法司法→行政审批→县委书记，属纪检系统晋升梯队。跨灵武、银川市直机关、贺兰县多地。

工作侧重（2026年第3次常委会）：工业经济、"四争"攻坚、教育优化布局。

风险信号：未检索到立案/处分/负面舆情（none_found）。

  • 惠农区尾闸镇党委副书记、镇长

跨县/跨市网络（彭小沛链路）：石嘴山惠农区 → 中卫沙坡头区 → 中宁 → 中卫市政府 → 银川贺兰县，属典型跨市干部交流。

纪检网络（杨爱军链路）：灵武市 → 银川市纪委/监委 → 西夏区纪委 → 贺兰县委，纪律检查系统内垂直履历。

银川市域内：兴庆区、金凤区、西夏区、灵武市、永宁县、贺兰县同属副省级城市银川管理。杨爱军曾在西夏区纪委书记、灵武市任职；丁炜以银川市人大常委会副主任身份兼贺兰县书记（市领导兼任县委书记惯例）。跨区干部交流以银川市直机关↔县区为主导。
