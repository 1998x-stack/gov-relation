5. 已知大邑县历史领导人

宋朝华（1997-2002年大邑县委书记）

来源：https://zh.wikipedia.org/wiki/宋朝华

基本信息：1962年5月出生，四川邛崃人，温江师范专科学校中文专业毕业

大邑任职经历：

  • 大邑县委组织部常务副部长 → 县委常委、组织部部长 → 县委副书记、组织部部长
  • 1997年3月 → 大邑县委副书记、县人民政府代县长、党组书记
  • 1997年10月 → 中共大邑县委书记
  • 2002年12月 → 转任中共新津县委书记

后续晋升：新津县委书记 → 成都市副市长 → 眉山市市长 → 南充市委书记 → 四川省人大常委会副主任（副省级）

曾万明（2002-2005年大邑县委书记）

来源：https://zh.wikipedia.org/wiki/曾万明

基本信息：1964年1月4日出生，四川成都人，西南财经大学农业经济学博士

大邑任职经历：

  • 此前任彭州市委副书记、市长
  • 2002年12月 → 大邑县委书记（接替宋朝华）
  • 2005年5月 → 升任成都市人民政府副市长

后续晋升：成都市副市长→ 绵阳市市长 → 内江市委书记 → 西藏/广西/湖南省委常委

备注：2021年9月8日逝世

李刚（1965年生，大邑本土成长干部）

来源：https://zh.wikipedia.org/wiki/李刚_(1965年)

基本信息：1965年7月出生，四川大邑人，电子科大工商管理硕士、中央党校经济学在职研究生

大邑任职经历：

  • 1982年12月 → 大邑县电力公司员工（17岁参加工作）
  • 1990年起 → 大邑县乡镇、地方税务局、组织部任职
  • 1997年12月 → 大邑县委常委、副县长
  • 后任大邑县委副书记
  • 2001年6月 → 调任温江县委副书记、县长

后续晋升：温江区 → 成都市 → 四川省经信委 → 四川省政府副秘书长 → 四川省副省长 → 云南省委常委、组织部长 → 2024年9月被查 → 2025年4月被开除党籍公职

备注：李刚是从大邑县基层（电力公司）成长起来的本土干部，其落马为近年四川省重要的反腐案件
