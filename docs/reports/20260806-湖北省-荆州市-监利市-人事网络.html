1. 现任市委书记：聂良平

  • 基本信息：男，汉族，湖北潜江人，1977年9月出生；1999年7月参加工作，1998年12月入党；大学本科，中国地质大学贸易经济专业。（confirmed）
  • 履历要点（confirmed，官方任命公告+多源）：
  • 1995.09—1999.06 中国地质大学贸易经济专业学习。
  • 1999.07—1999.08 荆州区川店镇工作；1999.08—2000.01 川店镇藤店管理区副主任；2000.01—2000.11 藤店管理区党总支副书记。
  • 2000.11—2020 历任荆州体系内职务（含地级市委组织部等，中段节点公开有限，见缺口）。
  • 2020年10月 任监利市人民政府副市长、代理市长。
  • 2021年1月8日 当选监利市人民政府市长。
  • 2025年12月 由市长转任监利市委书记，短暂兼任市委书记、市长（约2025-12中旬）。
  • 2025年12月27日 市二届人大常委会第三十次会议决定接受其辞去市长；12月31日 二届人大五次会议第三次全体会议确认 瞿俊森当选市长。
  • 现状：2026-02 荆州“新春第一会”后以监利市委书记身份发声；2026-02-27 全市建设先行区推进会、2026-05-18 市委深改委财经委会议、2026-05-30 市委全面依法治市委员会会议均由聂良平主持。（confirmed）
  • 晋升路径：荆州基层乡镇 → 市管干部 → 跨县任监利市长 → 市长接任书记。属“市长就地接任书记”模式。

2. 现任市委副书记、市长：瞿俊森

  • 基本信息：男，土家族，1985年1月生，湖北恩施人；中共党员；硕士研究生（清华大学法学院刑法学专业）；经济师。（confirmed，官方领导信息+凤凰网湖北）
  • 履历（confirmed，多源一致）：
  • 长期在荆州市沙市区工作：沙市区立新乡党委副书记、乡长；锣场镇党委书记；沙市区副区长；沙市经济开发区管委会主任。
  • 2021年9月 调任共青团荆州市委副书记（主持全面工作）；2021年12月 任共青团荆州市委书记。
  • 2023年10月 调任监利市委副书记、政法委书记（跨区交流入监利）。
  • 2025年12月27日 任监利市人民政府副市长、代理市长（市二届人大常委会第三十次会议）。
  • 2025年12月31日 当选监利市人民政府市长（二届人大五次会议第三次全体会议）。
  • 晋升模式：“沙市区（区县两级岗位）+ 共青团荆州书记 → 跨区（监利副书记/政法 → 市长）”，为荆州内跨区交流 + 政工系统转政府主政的典型。

2. 前任市委书记：韩旭（去向：荆州市委常委）

  • 男，汉族，河南邓州人，1982年1月出生；2008年7月参加工作，2006年6月入党；博士研究生（理学博士）。（confirmed）
  • 履历：2003—2008 中国科学技术大学硕博连读 → 2008 湖北省孝感市科技局 → 2009年6月跨省调任河南省濮阳工业园区管委会主任助理（副县级，27岁副县） → 濮阳市台前县县长（34岁当县长，"两次跨省"）→ 2020年6月19日 任监利县委书记（二次跨省回鄂，湖北首位博士县委书记、第2位80后区县委书记） → 2020 监利撤县设市，任监利市委书记 → 2022年1月 任荆州市副市长并继续担任监利市委书记 → 2025年3月 任荆州市委常委、卸任副市长，仍兼监利市委书记 → 2025年11月 拟任新职，卸任监利市委书记。
  • 继任：2025年12月 聂良平接任监利市委书记。（confirmed）

6. 周边县区人事交流线索

  • 监利地处荆州东南沿长江，与洪湖、公安、石首等沿江县级市县相邻。聂善由潜江（荆州西北）而来，瞿俊森由沙市（荆州中心区）/共青团而来，刘俊军由监利→洪湖→ 仙桃，均体现“荆州市域内县区+外流”两向交流。
  • 石首市长（前监利县副县长等）傅勇被查（2025-05），提示监利—石首、洪湖一线政法/政府岗位存在历史重叠与风险交集点（待进一步核实）。
