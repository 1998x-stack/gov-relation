网络搜索受限说明

本调研遇到以下网络访问障碍：

  • Exa 搜索 API：免费额度限流
  • 百度搜索/百科：403 验证码拦截
  • Jina Reader（r.jina.ai）：超时
  • 维基百科：连接失败
  • Google/Bing/DuckDuckGo：超时/被拦截

结论：当前网络环境严重依赖政府网站直接访问。已确认的信息来自大洼区政府官网（可通过 http 访问，但为 JS SPA，只能在首页获取部分信息）。更深入的履历查询需要更好的网络条件或其他搜索工具。
